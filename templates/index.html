💡 Helpful tips

  • Translation engines: Google Translate needs no setup. For better Malayalam quality, try IndicTrans2 (local AI) or Sarvam/Gemini (free API key).
  • Supported formats: PDF (text-based), Word DOCX, HTML, Markdown (.md), plain TXT.
  • Structure is preserved: headings, tables, bullet lists, and code blocks are kept intact in the translation.
  • Output format: choose DOCX (Word) for the best table and heading fidelity; PDF for a ready-to-print result.
  • Scanned image PDFs cannot be translated — the PDF must contain selectable text.
  • Translation time depends on file length and engine — IndicTrans2 is slower on CPU but highest quality.
